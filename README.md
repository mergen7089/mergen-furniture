# MERGEN Furniture

وب‌سایت MERGEN Furniture با هدف معرفی محصولات و خدمات حوزه مبلمان، دکوراسیون داخلی و تجهیزات چوبی توسعه داده شده است.

این پروژه با استفاده از HTML، Tailwind CSS و JavaScript ساخته شده و از کتابخانه Owl Carousel برای ایجاد اسلایدرها استفاده می‌کند.

## تکنولوژی‌ها

- HTML5
- Tailwind CSS 4
- JavaScript
- Owl Carousel
- jQuery
- Vazirmatn Font
- Font Awesome

## نصب و راه‌اندازی

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/mergen7089/mergen-furniture.git
```

وارد پوشه پروژه شوید:

```bash
cd mergen-furniture
```

وابستگی‌ها را نصب کنید:

```bash
npm install
```

## دستورات توسعه

برای اجرای Tailwind CSS در حالت توسعه:

```bash
npm run dev
```

این دستور تغییرات فایل‌های HTML و JavaScript را بررسی کرده و CSS را در مسیر زیر تولید یا به‌روزرسانی می‌کند:

```text
dist/css/style.css
```

برای تولید نسخه فشرده CSS:

```bash
npm run build
```

خروجی این دستور:

```text
dist/css/style.min.css
```
